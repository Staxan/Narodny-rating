# Народный рейтинг

Публичный веб-сервис постоянного общественного контроля за депутатами: проверяемые факты (обещания, результаты, доходы и имущество) плюс анонимная народная оценка граждан.

**Текущий статус:** Этап 1 — фронтенд (Next.js), данные мок-набором. Бэкенд и реальное голосование через Telegram подключаются на следующем этапе (по ТЗ 1.1).

## Структура

```
narodny-rating/
└── apps/
    └── web/          # Next.js 15 + TypeScript — публичный сайт
        └── src/
            ├── app/          # Страницы (App Router)
            ├── components/   # React-компоненты
            └── lib/          # Типы, мок-данные, логика рейтинга
```

## Запуск

```bash
cd apps/web
npm install
npm run dev      # режим разработки (http://localhost:3000)
npm run build    # production-сборка
npm start        # запуск собранной версии
```

## Страницы

| Маршрут | Назначение |
|---|---|
| `/` | Главная-дашборд: топ рейтинга, счётчики, лента изменений, баннер выборов |
| `/deputies` | Список депутатов с поиском и фильтрами (уровень, регион, фракция) |
| `/deputies/[slug]` | Карточка депутата: рейтинг по блокам, обещания, работа в парламенте, доходы, народная оценка |
| `/how-it-works` | Формула рейтинга и механизм защищённого голосования |
| `/vote` | Форма народной оценки (Этап 1 — UX-цикл без записи голоса) |

## Технологии

- Next.js 15 (App Router), React 19, TypeScript
- Дизайн-система «Clean Civic Tech»: navy `#0F172A` + teal `#0D9488`, Inter, плавные анимации (fade-up, анимированные шкалы и кольцо рейтинга, прорисовка графика)
- Mobile-first адаптивная вёрстка
